# Concept match notes

The included preview image is the visual target for the three skills.

Q / VOID CUT:
- purple/magenta core
- curved slash
- horizontal beam
- bright white core
- impact shock ring
- flying damage numbers

E / PHANTOM DASH:
- cyan/blue energy
- multiple afterimages
- horizontal motion beam
- blue impact burst

R / DOMAIN:
- gold/orange energy
- large circular domain
- radial beams
- large particle storm
- strong camera shake

The runtime implementation uses Canvas primitives rather than copying any third-party game assets.

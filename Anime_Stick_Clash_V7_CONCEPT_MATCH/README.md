# Anime Stick Clash V6 PRO

Bản nâng cấp tập trung vào combat/VFX:
- procedural stickman animation với body sway, limb swing, lean và after-image
- 3-hit combo
- dash trail
- crescent slash
- aura nova
- ultimate Heaven Breaker
- particle bursts, neon glow, slash arcs, rings, flashes, energy bolt
- hit-stop + camera shake
- enemy AI + elite waves
- lobby, fighter selection, save, daily reward
- mobile controls
- Poki commercial + rewarded hooks

Chạy bằng local static server để ES modules hoạt động tốt:
`python -m http.server 8000`
sau đó mở `http://localhost:8000`.

Đây là implementation original lấy cảm hứng từ nhịp combat anime; không sao chép trực tiếp asset/code độc quyền của video.
